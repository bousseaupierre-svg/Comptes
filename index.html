      Importer

      Déposez vos fichiers (plusieurs à la fois) : le compte est reconnu automatiquement. Les lignes déjà présentes sont ignorées ; les nouvelles sont catégorisées avec vos règles.

      Sauvegarde et restauration

      Exportez toutes les données de votre base dans un fichier JSON. Vous pourrez ensuite le réimporter pour ajouter les données manquantes ou mettre à jour celles déjà présentes.

      L’import fusionne les données : il ne supprime aucune ligne existante. Conservez vos fichiers de sauvegarde dans un endroit sûr.
